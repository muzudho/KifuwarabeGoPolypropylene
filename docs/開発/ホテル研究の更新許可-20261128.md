# ホテル研究中の更新許可

2026-11-28、利用者から「1系は変更してよい」「明日の6時まで、どんどん更新」と明示された。その後「もう2時間延ばして、朝8時まで研究を続けて」と指示され、期限を2時間延長した。

- 研究と更新許可の期限は2026-11-29 08:00 JST（日本時間）。この期限までは1系の大会版固定・上書き禁止という従前の指示を解除し、検証済みの研究成果を1系にも反映してよい。更新ごとの再確認は不要。
- NASには接続せず、Dドライブにコピー済みの資料を研究の基盤とする。
- 最新の利用者指示により、公開情報のウェブ検索・閲覧などの外部接続は使用してよい。従前の研究における外部通信一律禁止を解除する。Free Wi-Fi上で安全性を必要とする情報は送受信しない。認証情報・非公開設定・秘密の資料を検索語や外部サービスへの送信内容に含めない。公開情報の検索許可を、非公開データのアップロードやpushの許可として扱わない。restore・ダウンロードを研究再開のため無条件に実行するものではない。
- 変更に応じた検証を行い、採用根拠・配布先・検証結果を記録する。許可だけを根拠に未検証試作を配布しない。
- 期限以降の1系更新は、この期限付き許可を根拠に行わない。
- 大会は19路盤。調整・主要な自己対局は19路を対象とする。CGOSのリモート対局は利用者が停止する方針であり、こちらから再接続・再起動しない。
- 大会の持ち時間は30分で、合計約25分を思考に使ってよい（1手25分ではない）。研究の自己対局は短時間に保ち、多数の比較を進める。本番用の時間配分・読みの予算と研究用の短時間予算を区別する。単に待つ処理で時間を消費しない。この許可記録だけでは時間制御を実装したことにならない。

この記録自体では実行ファイル・主系設定・自動化の状態を変更していない。継続実行や予約タスクの新規設定を示すものではない。
