# 着手生成の時間上限

2026-11-28利用者指示：1手8秒を超える読みを打ち切り、それまでに検討した中で最も良い手を打つ。

Board.Generateの既定思考予算を7.5秒とし、8秒までの残りを着手適用と応答処理の余裕とする。単調時計Stopwatchで計測し、候補評価・盤面コピー・連の探索の入口で期限を確認する。genmoveとcgos-genmove_analyzeの両方に適用され、自己対局でも同じ入口を使う。Generate(color, TimeSpan)で短い研究用予算も指定できる（0～7.5秒）。

各候補について既存の全順位キーを計算し、合法性・保護地・予約角・局面反復・既知失敗・眼埋め・直後の捕獲損失を確認した後で、最良候補を更新する。順位キーは従来と同じ優先順で、同順位では点番号順。途中で期限に達した場合は、完了済み候補中の最良手を使う。評価途中の候補を採用せず、完了した採用可能候補が一つもなければパスする。全盤の最善手の保証ではない。

読みは実盤から隔離した盤面・履歴・経験・戦訓統計で実行。通常終了時のみ結果全体を反映し、時間切れなら作業盤を捨てて保存済みの一手だけを実盤へ適用する。LastGenerationTimedOutで打切りを判別できる。候補評価のための中断検査を行う協調的な方式であり、OSの停止・CPU停止・プロセス異常を含めた厳密な8秒以内の応答保証ではない。外部の強制終了監視は今回追加していない。
