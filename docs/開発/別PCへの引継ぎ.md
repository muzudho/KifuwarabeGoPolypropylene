## まず1回実行する

リポジトリー直下のPowerShell 7で実行します。

```powershell
.\scripts\Invoke-LessonCycle.ps1 -TimeoutSeconds 300 -Games 32 -Seed 2026112322
```

既定では実行日＋7日の `delete-after-YYYY-MM-DD/lesson-cycle/実行日時-seed番号` に保存されます。別PCの最初のSEEDは上の未検証値を使えます。比較する前後は同じSEED、次の観測サイクルは別のSEEDにします。

ドライブ文字が異なる場合は保存先を明示します。

```powershell
.\scripts\Invoke-LessonCycle.ps1 -TimeoutSeconds 300 -Games 32 -Seed 2026112322 -ArtifactRoot '\\TAKAHASHI-NAS\Share\muzudho-with-ai-agent\KifuwarabeGoPolypropylene\tmp\delete-after-2026-11-30\lesson-cycle'
```

日付は実行時に更新してください。スクリプトは指定パスのドライブ／共有が見えるか検査します。UNC指定を別PCで使う場合も、実際に手動試験してから定期実行に使ってください。

実行順はNAS内の隔離Releaseビルド→自己テスト→対局です。合計300秒で打ち切り、超過した子プロセスツリーを停止します。終了コード0は処理成功、1は実行失敗、2は時間切れです。400手での石数判定は時間切れと異なり、成功した対局結果です。

確認するファイル：

- `run-status.json`：実行状態、処理時間、保存先。
- `tests.stdout.log` / `tests.stderr.log`：現行基準は1361チェック成功。新しい検証を加えたら件数は変わります。
- `summary.json`：9路・19路別の400手判定・連続パス・タイムアウト・再出現。
- `games.jsonl`：棋譜、戦訓統計、失敗例。点番号はA1=0、左下から行順、nullはパス。
- `source-hashes.json`：実行ソースのSHA256。`build/` に固定ビルド。

NASが使えないときは大量のローカル代替出力を作らず終了してください。排他ロックを削除して競合を強行しないでください。ロックは同じArtifactRootを使う実行間で働くため、別のルートや日付を指定すると互いを排除できません。二重運用の防止は旧タスクの停止でも行います。

## 現行仕様を維持する

- 9路・19路が最終成果物。3路・5路は小さな失敗の再現・研究用。
- 利用者指定の純碁風ルール。盤上の黒白石数だけを比較。コミ・空点・取った石は加算しない。同数は引き分け。
- 黒白合計400手、パスも1手。400手目で盤面を固定して判定する。違法手は数えない。通常は連続2パスで終了。
- 合法手が残れば、戦訓で全候補を避けても合法手をフォールバックとして打つ。パスで逃げて収束したように見せない。
- 合法性は自殺手禁止と単純コウ。盤面再出現回避は着手方針で、相手の着手を超コウとして拒否する実装ではない。
- 面積計算用Board.Score(double)は研究用の残存ヘルパー。対局結果はCountStones()/StoneScore。中国式の面積計算へ戻さない。
- GUI・ロビー・通信はKifuwarabeGo2026側。思考エンジンは標準入出力GTP。通常起動の標準出力へ研究ログを混ぜない。

主なソース：Board.cs（盤面と着手選択）、BattleLessons.cs（統計と失敗例）、StoneScore.cs（勝敗）、GtpEngine.cs（接続）、LessonCycle.cs（研究対局）、SelfTest.cs（回帰テスト）。すべてKifuwarabeGoPolypropylene.ThinkEngine内です。

エンジン内にはrepeat-position、fill-eye、immediate-capture、capture-reversalの4種類があります。失敗候補を仮想実行して観測し、同じ局面・直前盤面・色・候補の経験を再利用します。未知の失敗から新しいC#のルールを作るのは定期研究のCodexです。エンジン単体に未知のルールの自動発明機能はありません。経験はプロセス終了後に保存されません。報告の回避数は候補を除外した試行回数で、最終フォールバックで採用する場合もあります。
